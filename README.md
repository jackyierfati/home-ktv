# 家庭KTV（Home KTV）

中文 | [English](README.en.md)

在家唱 K：歌存在自己的 NAS 或电脑上，**电视只管放，点歌、遥控、看排到第几都在手机上**。

明明是在家里，电视屏幕不需要花里胡哨的菜单和遥控器点歌。客人连上 WiFi、扫电视上的码，手机上就能搜歌、点歌、切歌、
看自己前面还有几首；NAS 上没有的歌点了就自动下载，下好自动开唱。

> 8 万首曲库来自 i歌霸 的公开接口。本项目不提供任何歌曲文件，只用于个人、家庭、非商业用途。

## 特点

**功能都在手机上**

- 扫码就能点歌：不用装 App，不用登录，不用会员。
- 搜歌名、歌手、拼音首字母都行（`qt` → 晴天，`zjl` → 周杰伦），热门的和 NAS 上已经有的排在前面。
- 已点列表：每首歌是谁点的、下载到多少了，可以置顶、删除；「我点的」显示前面还有几首、大约还要几分钟。
- 遥控：暂停、切歌、重唱、原唱/伴唱、音量。
- 点歌时留个昵称，电视上会弹出「小王 点了《晴天》」。

**电视上简简单单**

- 没人唱的时候：已点的歌、点歌二维码和连 WiFi 二维码、谁点了什么。
- 唱歌的时候：只在顶上一行显示歌名、谁点的、下一首，不挡画面。
- 遥控器只用几个键：OK 暂停，→ 切歌，↑↓ 原唱/伴唱，← 看已点和二维码。

**海外也能快速下歌**

歌源在国内，从海外下载又慢又容易卡住。下载器专门为这种网络写的：

- 每首歌切成 512 KiB 的小段，同时开 64 路连接下载。
- 一路连接 20 秒没数据就换一条重下；连续失败就换一个新的下载地址。
- 只剩最后几段时，卡住 6 秒的段再开一路，谁先下完用谁，不会卡在 99%。
- 取下载地址的接口偶尔不回应：每 5 秒再发一次，用最先回来的那个。
- 先写到 `.part` 文件，每个字节都到了才换成正式文件；坏了的歌可以在管理页重新下载，新的下完整才替换旧的。
- 客人点的歌插队先下，批量下载排在后面；队列存在硬盘上，重启接着下。
- 可以让下载单独走中国大陆出口（自带一个可选的 WireGuard 容器），家里其他流量不受影响。

在海外经中国大陆出口实测：每首 0.3 ~ 1.8 MiB/s，一首 70 MB 左右的歌一两分钟下好。

**部署简单**

- 服务端只用 Python 标准库，一个官方 `python:3.12-slim` 镜像就能跑，不用构建镜像，不用装依赖。
- 任何能跑 Docker 的机器都行：TrueNAS、群晖、Unraid、树莓派、普通的 Linux 或 Windows 电脑。
- 下过的歌存在自己硬盘上，第二次点秒开；管理页可以按歌手、歌单、排行榜批量下载。

## 整体结构

```
手机 / 电脑浏览器 ──┐
                    ├─HTTP─▶ ktv-server（Docker，端口 8787）── 可选代理 ──▶ i歌霸 曲库和歌曲
电视上的播放器 ─────┘          ├─ 点歌网页  /        给客人用
  （Android TV）               ├─ 管理页    /admin   批量下载、设置
                               ├─ 电视主页  /tv      播放器里显示的界面
                               ├─ 已点、下载队列、曲库（SQLite）
                               └─ 歌曲文件 /media/<编号>（MKV，支持断点续传）
```

- `ktv-server/`：服务端（Python）。
- `ktv-player/`：Android TV 播放器（Kotlin + Media3）。它只管放视频，界面是服务端上的 `/tv` 网页，改界面不用重装 App。
- 详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 快速开始

需要：一台局域网里能跑 Docker 的机器，一台 Android TV 设备（在 Chromecast with Google TV 上测试过），手机和电视在同一个 WiFi。

```bash
git clone https://github.com/jackyierfati/home-ktv.git
cd home-ktv
cp .env.example .env        # 改 KTV_MEDIA：歌曲存哪里，空间要大
docker compose up -d
```

1. 浏览器打开 `http://<这台机器的 IP>:8787/admin` →「曲库与设置」→「更新曲库」，等几分钟。
2. 在管理页「名字」里填上你家的 KTV 名字；想让朋友扫码连 WiFi 的话，填上 WiFi 名称和密码。
3. 电视上装播放器（见 [ktv-player/README.md](ktv-player/README.md)），第一次打开输入 `http://<这台机器的 IP>:8787`。
4. 手机扫电视上的「扫码点歌」，开唱。

在国外的话，再看 [docs/DEPLOY.md](docs/DEPLOY.md) 里「让下载走中国大陆出口」一节。

## 麦克风

麦克风不经过这套系统。推荐的接法是电视盒子用 HDMI 接混音器（或带 HDMI 的 K 歌功放），人声由混音器处理，没有延迟。

## 安全

点歌网页和管理页都没有密码，只适合在家里局域网用。**不要把 8787 端口映射到公网。**
